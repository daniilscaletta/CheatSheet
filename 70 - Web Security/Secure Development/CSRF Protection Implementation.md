> **Кастомный вариант**
### При аутентификации через токены - **CSRF НЕТ!**

### Защищаемся только в случае cookie-session
1) Использовать Double Submit - Подставляем токен и в куку и в запрос, тогда они должны совпасть
2) Использовать CSRF вместе с модифицирующими запросами
3) Не использовать в мобильном API аутентификацию по кукам
