### Taint Analisis

- Source - источник, откуда приходят данные
- Sink - места, при попадании в которые полученных данных происходит уязвимость
- Propagators - помечаются данные, если они потенциально могут вызвать уязвимость
- Sanitizers - места, в которых устраняются потенциальные уязвимости
