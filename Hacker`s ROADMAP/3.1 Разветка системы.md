## Сбор информации о пользователях и группах

Информация о нас:
```bash
id
who
w
last
cat /etc/passwd | cut -d: -f1    # List of users
grep -v -E "^#" /etc/passwd | awk -F: '$3 == 0 { print $1}'   # List of super users
awk -F: '($3 == "0") {print}' /etc/passwd   # List of super users
cat /etc/sudoers
sudo -l
```

Поиск файлов для повышения привилегий:
- _Sticky bit_
- _SUID_
- _SGID_
```bash
find / -perm -1000 -type d 2>/dev/null   # Sticky bit — только владелец директории и/или файла может удалять или переименовывать

find / -perm -g=s -type f 2>/dev/null    # SGID (chmod 2000) — запускается от имени (с правами) группы, а не пользователя непосредственно давшего старт процессу

find / -perm -u=s -type f 2>/dev/null    # SUID (chmod 4000) — запускается от имени владельца
 
find / -perm -g=s -o -perm -u=s -type f 2>/dev/null    # SGID or SUID
```
