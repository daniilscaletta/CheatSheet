> Цель - найти максимальное количество узлов в локальной сети и провести атаки первичного доступа

![[Разветка и компрометация внутренней сети.png]]
1) Необходимо обнаружить и компрометировать любую Windows машину, потому что все они связаны по AD
2) Анализировать трафик в этой локальной сети: можно искать популярные Windows сервисы: SMB, LDAP, MSRPC

### Атаки на Windows машины
1) Атаки на известные уязвимости
2) Bruteforce учетных данных
3) MITM

### Обнаружение Windows машин в локальной сети
1) Обнаружить сервисы, которые могут принадлежать Windows машинам:
	- 88 - **Kerberos** (Помогает в определении контроллера домена)
	- 135 - **MSRPC** (Используется при обменене инфой между клинт-сервером)
	- 137 - **`NetBIOS-NS`** (Позволяет узнавать доменное имя машины и ее MAC-адрес)
	- 389 - **LDAP** (Доступ к AD или получение учетных данных
	- 445 - **SMB** (Сервис для создания и доступа к расшаренным папкам)
	- 1433 - **MSSQL** (Сервер позволяет при получении доступа выполнять прямые запросы к БД)
	- 3389 - **RDP** (Протокол удаленного доступа, имеющий уязвимости к MITM)
2) Анализ трафика широковещательных запросов
	- **NBT-NS (Преобразование имен NetBIOS в IP адреса локальной сети)**
	- **LLMNR (Разрешение имен хостов в сети)**
	- **WPAD (Протокол автоматической настройки прокси)**

### Компрометация Windows машин
1) Использование известных уязвимостей, эксплойтов,  [CVE](https://github.com/SecWiki/windows-kernel-exploits)
2) Брут учетных записей
	- Необходимо подобрать список логинов
	- Использовать атаку методом Password Spraying
3) Перехватить трафик и воспользоваться атакой **LLMNR / NBT-NS / MDNS Spoofing**
	- В момент выполнения алгоритма на этапе **LLMNR / NBT-NS / MDNS** по разрешению доменных имен мы можем подменить ответ и завести жертву на свой ресурс


### **LLMNR / NBT-NS Spoofing**

![[LLMNR or NBT-NS Spoofing.png]]
Необходимо заставить жертву перейти на контролируемый ресурс.
Далее после отправки пользователем данных аутентификации ресур получит NTLM - хэши, которые впоследствии можно сбрутить.

1) [Responder]([https://github.com/SpiderLabs/Responder](https://github.com/SpiderLabs/Responder))
