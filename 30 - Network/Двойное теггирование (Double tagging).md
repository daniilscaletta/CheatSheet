#vlan #attacks

> Применяется для проникновения к жертве через VLAN, путем инкапсуляции тегов

![[VLAN Hopping.png]]

Атака происходит, если свич настроен на Native VLAN, из-за чего он снимает только один тег
## Атака

1) Создается фрейм с двумя тегами
```bash
yersinia -G
```

2) Отправляется пакет на VLAN 1 (Native)
```
Double tagging attack
# Указываем параметры:

## Оглавление
- [[#Атака]]
- [[#Tools:]]

---

# - Native VLAN: 1
# - Target VLAN: 10  
# - Destination IP: 192.168.10.100
```

3) Получаем доступ к виртуальной сети жертвы
## Tools:
