#windows #AD #privillage #group 

| **Группа**                             | **Описание**                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Администраторы                         | Администраторы домена и администраторы предприятия являются «супергруппами».                                                                                                                                                                                                                                                                                                                                                                                                              |
| Операторы серверов                     | Участники могут изменять настройки сервисов, получать доступ к общим ресурсам SMB и создавать резервные копии файлов.                                                                                                                                                                                                                                                                                                                                                                     |
| Резервные операторы                    | Члены группы могут входить в систему контроллеров домена локально и должны считаться администраторами домена. Они могут создавать теневые копии базы данных SAM/NTDS, удаленно читать реестр и получать доступ к файловой системе на контроллере домена через SMB. На контроллерах домена, не являющихся контроллерами домена, эта группа иногда добавляется в локальную группу операторов резервного копирования.                                                                        |
| Операторы печати                       | Участники могут локально подключаться к контроллерам домена и "обмануть" Windows, заставив её загрузить вредоносный драйвер.                                                                                                                                                                                                                                                                                                                                                              |
| Администраторы Hyper-V                 | Если имеются виртуальные контроллеры домена, то любые администраторы виртуализации, например, члены группы администраторов Hyper-V, должны считаться администраторами домена.                                                                                                                                                                                                                                                                                                             |
| Операторы учетных записей              | Участники могут изменять незащищенные учетные записи и группы в домене.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Пользователи удалённого рабочего стола | Участникам по умолчанию не предоставляются никакие полезные разрешения, но им часто предоставляются дополнительные права, такие как... `Allow Login Through Remote Desktop Services`и может перемещаться вбок, используя протокол RDP.                                                                                                                                                                                                                                                    |
| Пользователи удаленного управления     | Участники могут подключаться к контроллерам домена с помощью PSRemoting (эта группа иногда добавляется в локальную группу удаленного управления на серверах, не являющихся контроллерами домена).                                                                                                                                                                                                                                                                                         |
| Владельцы создателя групповой политики | Участники могут создавать новые групповые политики (GPO), но для привязки GPO к контейнеру, такому как домен или организационное подразделение (OU), им потребуются дополнительные права доступа.                                                                                                                                                                                                                                                                                         |
| Администраторы схемы                   | Участники могут изменять структуру схемы Active Directory и создавать обходные пути для любых групп/объектов групповой политики, добавляя скомпрометированную учетную запись в список контроля доступа (ACL) объекта по умолчанию.                                                                                                                                                                                                                                                        |
| Администраторы DNS                     | Участники группы могут загрузить DLL-файл на контроллере домена, но не имеют необходимых разрешений для перезапуска DNS-сервера. Они могут загрузить вредоносный DLL-файл и дождаться перезагрузки в качестве механизма обеспечения постоянного присутствия в системе. Загрузка DLL-файла часто приводит к сбою службы. Более надежный способ эксплуатации этой группы — создание [записи WPAD](https://web.archive.org/web/20231115070425/https://cube0x0.github.io/Pocing-Beyond-DA/) . |
