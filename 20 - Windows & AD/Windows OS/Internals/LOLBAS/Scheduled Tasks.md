Перечисление запланированных задач

```cmd
schtasks /query /fo LIST /v
```

```powershell
Get-ScheduledTask | select TaskName,State
```

Мы (хотя и редко) можем столкнуться с запланированной задачей, которая запускается от имени администратора и имеет слабые права доступа к файлам/папкам по разным причинам. В этом случае мы можем отредактировать саму задачу, чтобы выполнить непредусмотренное действие, или изменить скрипт, запускаемый запланированной задачей.

1) Находим папку и проверяем права на нее
```
.\accesschk64.exe /accepteula -s -d C:\Scripts\
```

2) Вставляем в скрипт фрагмент кода для отправки маяка к нам на сервер, для убеждения, что скрипт рабоатет

3) Далее уже делаем, все что угодно
