#windows #AD #ADCS 

> ADCS - Это минное поле

> **Active Directory Certificate Services (AD CS)** — это роль сервера в операционных системах Windows Server, которая позволяет развертывать инфраструктуру открытых ключей (**PKI**, Public Key Infrastructure). Простыми словами, это ваш собственный локальный центр сертификации.

# Что это и для чего нужно?

AD CS выдает цифровые сертификаты, которые служат своего рода «паспортами» для пользователей, компьютеров и сервисов внутри домена. Эти сертификаты позволяют:

- **Подтверждать личность:** Удостоверяться, что компьютер или пользователь именно тот, за кого себя выдает.
- **Шифровать данные:** Использовать асимметричное шифрование для защиты переписки или файлов.
- **Обеспечивать целостность:** Подписывать документы или код, чтобы гарантировать отсутствие изменений.

# Как используется в инфраструктуре?

В реальной сети AD CS чаще всего применяется для следующих задач:

1. **Аутентификация по смарт-картам:** Вход в Windows без пароля.
2. **Шифрование веб-трафика (SSL/TLS):** Создание доверенных HTTPS-соединений для внутренних сайтов (например, корпоративного портала или Outlook Web Access).
3. **Защита VPN и Wi-Fi:** Использование сертификатов вместо логина/пароля для доступа к корпоративной сети.
4. **EFS (Encrypting File System):** Шифрование файлов на жестких дисках пользователей.
5. **Подпись кода:** Гарантия того, что внутреннее ПО написано вашими разработчиками.
