## Windows Hello
Это «потребительская» версия. Она работает локально на конкретном устройстве.

Создает привязку между биометрией (лицо/отпечаток) и локальным паролем пользователя.

- при использовании PIN кода пароль пользователя будет зашифрован на пин коде по протоколу `dpapi-ng` а также с использованием TPM (Trusted Platform Module)
- при использовании биометрии пароль хранится с использованием `dpapi-ng`, <span style="background:#ff4d4f">НО хранится он там в открытом виде</span>


## Windows Hello for Business
Это корпоративное решение, которое полностью меняет логику входа в домен, использует аутентификацию по серификатам

Используется для выдачи сертификата пользователю, <span style="background:rgba(3, 135, 102, 0.2)">но только после предоставления 2FA</span>

- Пользователь открывает свою систему ТОЛЬКО по `биометрии`
- `msds-KeyCredentialLink`(Key Trust) - аттрибут содержит либо публичный ключи, либо сертификат
<font color="#ffff00">НО здесь есть нюанс</font>
<font color="#ffff00">	- Если пользователи не могут его изменять</font>
<font color="#ffff00">	- То компьютер может его себе прописать (Аналог RBCD)</font>
