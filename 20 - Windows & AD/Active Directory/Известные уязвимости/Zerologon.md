CVE-2020-1472
#### Возникновения уязвимости
Уязвимость заключается в реализации протокола шифрования AES-CFB8 при аутентификации по _Netlogon Remote Protocol_ (_MS-NRPC_). 

При шифровании этим протоколом последовательности нулей, зашифрованная последовательность также будет состоять только из нулей. Это происходит из-за ошибки реализации для 1 из 256 ключей

Атака осуществляется через добавление нулей в _nonce_-параметр (_number used once_) _Netlogon_, что и дало название уязвимости. Ошибка при этом на уровне протокола и представляет угрозу для всех реализаций _SMB_, включая _Samba_ до версии 4.8, что делает уязвимыми и _Linux_-машины.

#### Импакт
_Zerologon_ позволяет злоумышленнику:
- выдать себя за любой компьютер домена в ходе аутентификации на _DC_;
- отключить защитные механизмы при аутентификации _Netlogon_;
- изменить пароль компьютера в _Active Directory_ контроллера домена.

#### Уязвимые версии:
- все версии _Windows Server 2019_, _Windows Server 2016_;
- _Windows Server 2004_, _1909_, _1903_;
- _Windows Server_ версии _1809_ (_Datacenter_, _Standard_);
- _Windows Server 2012 R2/2012_;
- _Windows Server 2008 R2 Service Pack 1_.
