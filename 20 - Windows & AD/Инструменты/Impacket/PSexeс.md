## Как работает

Для работы необходимы все креды и домен

`impacket-psexec`
Запускает модуль, который:
- аутентифицируется по `SMB` (445)
- копирует исполняемый `payload`
- создаёт Windows-службу (во временной папке)
- запускает команду
- даёт тебе интерактивную `shell`
После окончания `payload` удаляется

## Использование

```bash
impacket-psexec <domain>/<user>:'<pass>'@<target_ip> -dc-ip <dc_ip>
```
