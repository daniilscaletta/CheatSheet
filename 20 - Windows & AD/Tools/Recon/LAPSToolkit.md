#LAPS #Password #Policy

## 1) Find-LAPSDelegatedGroups
Проверяет какие группы Active Directory имеют право на чтение атрибута `ms-Mcs-AdmPwd`

## 2) Find-AdmPwdExtendedRights
Проверяет права доступа на каждом компьютере с включенным LAPS для любых групп с правами на чтение и пользователей с «Всеми расширенными правами»

## 3) Find-LAPSComputers
Поиск компьютеров с открытыми паролями Администратора
