[[Linux Administration#Capabilities]], Позволяющие повыситься до `root`

| **Возможности**    | **Описание**                                                                                                                                                                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cap_setuid`       | Позволяет процессу установить свой эффективный идентификатор пользователя, который может быть использован для получения привилегий другого пользователя, включая `root` пользователь.                                                                               |
| `cap_setgid`       | Позволяет установить эффективный идентификатор группы, который может быть использован для получения привилегий другой группы, включая `root` группа.                                                                                                                |
| `cap_sys_admin`    | Эта возможность предоставляет широкий спектр административных привилегий, включая возможность выполнения многих действий, зарезервированных для `root`пользователь, например, изменение системных настроек, а также монтирование и размонтирование файловых систем. |
| `cap_dac_override` | Позволяет обходить проверки прав на чтение, запись и выполнение файлов.                                                                                                                                                                                             |

Поиск файлов с установленными `capabilities`
```bash
find /usr/bin /usr/sbin /usr/local/bin /usr/local/sbin -type f -exec getcap {} \;
```
