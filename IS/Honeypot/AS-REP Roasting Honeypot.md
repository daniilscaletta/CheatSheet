## Создание AS-REPReroast Service Account Honeypot

Для того чтобы стать эффективным пользователем ловушки для мобов, необходимо обеспечить следующее:

- Учетная запись должна принадлежать относительно старому пользователю, в идеале — тому, кто стал фиктивным (опытные злоумышленники не будут запрашивать тикеты для новых учетных записей, поскольку у них, скорее всего, надежные пароли и есть вероятность, что они являются ловушкой для злоумышленников).

- Для пользователей служебных учетных записей пароль в идеале должен быть старше двух лет. Для обычных пользователей пароль следует поддерживать в актуальном состоянии таким образом, чтобы он не был старше одного года.

- Для этой учетной записи необходимо иметь учетные записи, в которые осуществлялся вход после дня смены пароля; в противном случае, если день последней смены пароля совпадает с днем ​​предыдущего входа, это становится очевидным.

- У учетной записи должны быть определенные права доступа; в противном случае попытка взломать хэш ее пароля не будет иметь смысла.
