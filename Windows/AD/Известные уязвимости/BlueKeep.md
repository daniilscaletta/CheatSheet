# _DejaBlue_ (ранее _BlueKeep-2_)
Все новые версии Windows

Ошибка была не в виртуальных каналах, а в **декомпрессии данных**. RDP сжимает изображение экрана, чтобы оно не тормозило. В модуле, который отвечает за распаковку этих данных, нашли переполнение буфера (Heap Overflow).
### Как эксплуатируется?

Хакер отправляет специально сжатый пакет данных. При попытке его «разжать», служба RDP выделяет недостаточно памяти, данные перезаписывают соседние ячейки, и — привет, выполнение кода.

#### Защита
Обеспечить удалённый доступ через шлюзы _Remote Desktop Gateway_ (_RDG_) и _VPN Gateway_ для _RDP_ и _VPN_ подключений соответственно. И исключить прямые подключения.

Использовать проверки подлинности на уровне сети (_NLA_)
