CVE-2020-0796

#### Возникновения уязвимости
Эксплуатирует уязвимость SMBv3

В отношении сервера _SMB_, злоумышленник, непрошедший проверку подлинности, может отправить специально созданный пакет на целевой сервер _SMBv3_.  
Для клиентов злоумышленнику необходимо настроить вредоносный сервер _SMBv3_ и убедить пользователя подключиться к нему.

Отсутствует проверка значения **`OriginalCompressedSegmentSize`** на достоверность, из-за чего при сжатии возникает переполнение буфера

#### Импакт
Удалённое выполнение кода с правами SYSTEM

#### Уязвимые версии:
Все версии OC Windows

#### Защита
- Установить последние обновления безопасности на все узлы с _Windows_
- Заблокировать _TCP_ порт 445 на внешнем периметре
- Отключить сжатие _SMBv3_.
