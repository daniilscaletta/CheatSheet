CVE-2021-34527

#### Возникновения уязвимости
Ошибка в службе диспетчера печати Windows (Print Spooler)

Для работы с драйверами через ядро нужны права SYSTEM, уяза возникала из-за неправильной проверки прав 

Ошибка в коде приводит к недостаточной валидации ввода в ходе добавления нового принтера. В результате появляется возможность загрузить в систему вредоносный DLL-файл. Повторная попытка «добавить принтер» позволяет обратиться к этому файлу, который запустится с системными привилегиями

#### Импакт
Полный контроль над системой

#### Уязвимые версии:
Все версии ОС Windows и Windows Server

#### Защита
Данный сервис по кмолчанию включен везде
Необходимо отключить службу печати (_Spooler_) там, где она не используется
