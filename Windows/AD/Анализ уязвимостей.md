#windows #AD 

## Общий принцип:

1) Скан открытых портов наиболее уязвимы протоколов
2) Попытаться определить версию протокола по пакетам, получаемых по найденным портам.
3) Взять соответствующие эксплойты и попробовать их применить.


## **Инструменты**

### 1)  Masscan
АССИНХРОННЫЙ СКАНЕР [(here)](https://github.com/SkillfactoryCoding/HACKER-LateralMovement-masscan)

Определить доступ портов в диапазоне адресов
```sh
masscan 192.168.0.0/24 -p80,443-445,8000-8089 --rate=100000 --wait=1 
# rate - кол-во/сек 
# wate - ожидание/сек
```

Определение всех открытых портов
```bash
masscan 192.168.0.35 -p0-65535 --rate=100000 --wait=1
```

Вывод в определенном формате
```bash
masscan 188.140.244.106 -p0-65535 --rate=100000 --wait=1 -oJ scan.json
masscan 188.140.244.106 -p0-65535 --rate=100000 --wait=1 -oX scan.xml
masscan 188.140.244.106 -p0-65535 --rate=100000 --wait=1 -oG scan.grep
masscan 188.140.244.106 -p0-65535 --rate=100000 --wait=1 -oL scan.list
```

Скан всего интеренета
```bash
masscan 0.0.0.0/0 -p0-65535
```

Разбитие сканирования на несколько хостов
```bash
masscan 0.0.0.0/0 -p0-65535 --shard 1/3
masscan 0.0.0.0/0 -p0-65535 --shard 2/3
masscan 0.0.0.0/0 -p0-65535 --shard 3/3
```

Используем баннеры служб
```bash
masscan 192.168.0.4/8 -p80,443 --banners --adapter-ip 192.168.1.1
                                         --source-ip 192.168.1.1
# --adapter-ip/--source-ip - Подмена адреса для обхода фаервола
```
