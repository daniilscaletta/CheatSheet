# Меры

## 1) **Local Administrator Password Solution** (LAPS)

Политика безопасности Microsoft для управления паролями локальных администраторов в домене Active Directory.

LAPS Предлагает:
- Автоматическая ротация уникальных сложных паролей для локальной учетной записи администратора на каждом компьютере с централизованным безопасным хранением в **AD**

## 2) Ведение журналов и мониторинга

Необходимо качественно и грамотно настроить аудит и мониторинг за событиям, чтобы своевременно пресекать атаки

## 4) Управление обновлениями (SCCM/WSUS)

Служба обновления Windows Server (WSUS) может быть установлена ​​в качестве роли на сервере Windows и может использоваться для минимизации ручной работы по обновлению систем Windows. Решение для управления обновлениями может помочь обеспечить своевременное развертывание исправлений и максимальное покрытие, гарантируя, что ни один хост не пропустит критически важные обновления безопасности.

## 5) Групповые учетные записи управляемых сервисов gMSA

**gMSA** — это специальный тип учетной записи службы Windows, который:
- **Автоматически меняет пароль** каждые 30 дней
- **Один аккаунт** для нескольких серверов в группе
- **Управляется доменом**, а не администратором вручную
- **Не требует ручного ввода пароля**

## 6) Ограничение использования учетной записи администратора домена

Использовать УЗ администраторов только для входа на контроллер домена, чтобы его пароль не хранился в памяти локальных машин
