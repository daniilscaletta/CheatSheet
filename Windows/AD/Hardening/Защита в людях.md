#windows #AD #hardening 

- В организации должна быть строгая политика паролей с фильтром, запрещающим использование распространенных слов (например, «приветствие», «пароль», названия месяцев/дней/времен года и название компании). По возможности следует использовать корпоративный менеджер паролей, чтобы помочь пользователям выбирать и использовать сложные пароли.

- Периодически меняйте пароли для **всех** учетных записей служб.

- Запретить локальный административный доступ на рабочих станциях пользователей, за исключением случаев, когда в этом есть конкретная необходимость.

- Отключить значение по умолчанию `RID-500 local admin`Создайте новую учетную запись администратора для управления системой с учетом ротации паролей LAPS.

- Внедрите разделение уровней администрирования для административных пользователей. Слишком часто во время проверки вы получаете доступ к учетным данным администратора домена на компьютере, который администратор использует для всех своих рабочих задач.

- Очистите привилегированные группы. `Does the organization need 50+ Domain/Enterprise Admins?`Ограничьте членство в группах с высокими привилегиями только для тех пользователей, которым этот доступ необходим для выполнения повседневных обязанностей системного администратора.

- При необходимости разместите счета в <font color="#00b050">`Protected Users`</font> группа.

- Отключите <font color="#00b050">делегирование Kerberos</font> для административных учетных записей (группа защищенных пользователей не может этого сделать).
