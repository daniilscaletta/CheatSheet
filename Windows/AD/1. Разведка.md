## Ручное тестирование
Мы можем использовать стандартные срадства, такие как PowerShell, чтобы изучить AD

Получить инфу обо всех юзерах домена:
```powershell
Get-ADUser -Filter * -properties *
```

Получить инфу обо всех группах домена:
```powershell
get-adgroup -filter * -properties *
```

Получить инфу о доменах, юзерах, группах и тд:
```powershell
net user /domain
```

## Автоматизированное тестирование

### 1) [BloodHound](https://github.com/SkillfactoryCoding/HACKER-OS-BloodHound)/[SharpHound](https://bloodhound.readthedocs.io/en/latest/data-collection/sharphound.html)

Получение инфы по AD
BloodHound - Серверная часть
SharpHound - коллектрор (exe/ps скрипт)

#### Использование
1) Скачиваем и запускаем Neo4j
2) Создаем пустую БД, запоминаем пароль
3) Включаем коллектор SharpHound, получаем архив с данными об AD
4) Аплоадим архив в BloodHound и смотри структуру

### 2) [ADRecon](https://github.com/SkillfactoryCoding/HACKER-OS-ADRecon)

Разведка домена 

Позволяет собирать и анализироватть:
- Domain Admins / Enterprise Admins / привилегированные группы
- Учётные записи без требования pre‑auth (AS‑REP roastable) и те, у кого нет Kerberos preauth
- ACL / права на объекты
- Учётки с правом «Replicating Directory Changes / DCSync»
- Локальные админы на множестве хостов
- Незащищённые GPO, скрипты логина, общие ресурсы (share) с конфиденциальными файлами
- Сервисные аккаунты с широкими правами (особенно те, что используют в скриптах/файлах)
- Ищем группы и пользователей, опираясь на свои цели (например, ищем бухгалтерию с целью подтверждения риска хищения денег и т.д.)
- SPN


### 3) [Impacket](https://github.com/CraigDonkin/Infrastructure/wiki/Impacket)

Куча инструментов для анализа доменов AD, AD в целом, проведения атак
Все тулзы [здесь](https://github.com/SkillfactoryCoding/HACKER-OS-impacket)

Также позволяет:
1) Проверить пользователей без предварительной аутентификации Kerberos (атака AS-REP Roasting) (_GetNPUsers.py_)
2) Получить [PAC](https://stealthbits.com/blog/what-is-the-kerberos-pac/) пользователя (_getPac.py_)
3) Получить информацию о SPN (_GetUserSPNs.py_)


### 4) [PowerUpSQL](https://github.com/SkillfactoryCoding/HACKER-OS-PowerUpSQL) 
Изучив _SPN_ и обнаружив там базы данных, можно использовать _powershell_ для атаки на них. Это довольно гибкая утилита, позволяющая провести поиск и эксплуатацию уязвимостей баз данных, в том числе, если у вас уже есть учётные данные.


### 5) Анализ Sysvol

Путь до _sysvol_: \\\contoso.local\SYSVOL\contoso.local\Policies\id_GPO
В папке групповых политик нас интересуют файлы _XML_, которые могут содержать в себе «зашифрованный» пароль:

- _Groups.xml_.
- _Services.xml_.
- _Scheduledtasks.xml_.
- _DataSources.xml_.
- _Printers.xml_.
- _Drives.xml_.

Искать пароли и взламывать хэши можно при помощи [PowerSploit](https://github.com/SkillfactoryCoding/HACKER-OS-PowerSploit) либо прям PowerShell:

```powershell
findstr /S /I cpassword \\<FQDN>\sysvol\<FQDN>\policies\*.xml
```
