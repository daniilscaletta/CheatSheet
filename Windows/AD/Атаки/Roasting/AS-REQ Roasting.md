#AD #windows #privillage #attacks #auth 

Эта атака не использует ошибки конфигурации, она следует сразу после MITM 

> Когда клиент отправляет запрос на первичную аутентификацию на KDC (AS-REQ) в нем он отправляет структуру со своими секретом и timestamp, атакер перехватывает эту структуру и брутит timestamp, получая в последствие секрет пользователя

## Эксплуатация 

Для начала необходимо проснифать трафик и достать AS-REQ пакеты 

далее уже при помощи тулзы [PCredz](https://github.com/lgandx/PCredz) достать и расшифровать секреты

```bash
Pcredz -f "file-to-parse.pcap"

Pcredz -i $INTERFACE -v
```


## Защита 

1) FAST (Flexible Authentication Secure Tunneling) - это защищённый туннель внутри Kerberos, который шифрует аутентификацию, чтобы её нельзя было перехватить
2) Armoring - использование FAST для упаковки предварительной аутентификации в криптографический тоннель
