#tool #windows #recon 

Это базовый инструмент разведки для Windows AD, работает на протоколе SMB/RPC.
Использует системные  команды для сбора полной информации о домене

Использует `SMB` (445) и `RPC`

Обертка над: 
1) `smbclient`
2) `rpcclient`
3) `net`
4) `nmblookup`

### Эксплуатация

Полный перебор всего (без кредов)
```bash
enum4linux-ng -A <ip>
```

Полный перебор всего (С любыми кредами)
```bash
enum4linux-ng -A <ip> -u <user> -p 'pass'
```



Полный перебор всего (простой инструмент)
```bash
enum4linux -a <ip>
```
